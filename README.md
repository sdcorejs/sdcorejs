## What I focus on

- **Reusable product foundations** — components and complete workflows that teams can use across applications.
- **Fullstack architecture** — clear module boundaries, typed contracts, and consistent integration patterns.
- **AI-assisted engineering** — turning requirements into explicit specifications, implementation plans, reviewed code, and verified outcomes.
- **Developer experience** — useful documentation, practical examples, predictable APIs, and reliable releases.
