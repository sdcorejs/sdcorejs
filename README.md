## Hi, I'm Nghĩa 👋

I'm a fullstack engineer based in Vietnam and the creator behind **SD CoreJS**.

My work spans UI component libraries, backend foundations, business applications, and AI-assisted software development. I turn recurring engineering problems into reusable tools, with a focus on clear APIs, consistent user experiences, and maintainable code.
